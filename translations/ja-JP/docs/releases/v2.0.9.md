# v2.0.9 - レシピのクライアントヒント

> 開発プレリリース版。このリリースは `dev` から公開され、迅速なフォローアップ変更を受ける可能性があり、デフォルトの `latest` イメージでは選択されません。

## 概要

v2.0.9 は `GET /api/v1/uploads/recipe` にクライアント向けヒントを追加し、ブラウザーが
ハードコードされた値ではなくサーバー側ポリシーに基づいてアップロードパイプラインの規模を
決められるようにします。既存フィールドの名前・型・意味は変わらず、新しいキーは追加のみ
なので、以前のリリース向けに作られたクライアントもそのまま応答を解析できます。

サーバーは引き続きすべてのリクエストを独立して検証します。ヒントがサーバーの受け入れ範囲を
広げることはありません。

## 変更内容

### レシピのクライアントヒント

- `max_source_bytes`（既定 `15728640`、`V2_MAX_SOURCE_BYTES` で 1 MiB から 64 MiB）：
  処理前にブラウザーが受け付けるソースファイルの上限です。
- `client_pipeline_concurrency`（既定 `2`、`CLIENT_UPLOAD_PIPELINE_CONCURRENCY` で
  1 から 8）：ブラウザー側アップロードパイプラインの並行数のヒントです。
- `client_active_session_concurrency`（既定 `4`、
  `CLIENT_ACTIVE_SESSION_CONCURRENCY`）：同時アップロードセッション数のヒントです。
  `V2_MAX_ACTIVE_SESSIONS_PER_USER` を超えてはならず、サーバー側の上限を下げる場合は
  この値も下げる必要があります。
- `client_max_native_concurrency`（既定 `2`、`CLIENT_MAX_NATIVE_CONCURRENCY` で
  1 から 4）：ネイティブ（Canvas/Pica）処理の並行数のヒントです。
- `supported_source_mime_types` はレシピが受け付けるソース形式を反映します。
- 4 つの新しい変数の設定エラーは MySQL に接続する前に起動を停止させ、有効値は起動サマリー
  ログに出力されます。

### ドキュメント

- `docs/API.md` は新しいキーを記載し、完全なレシピ応答例を掲載します。`docs/USAGE.md` は
  4 つの新しい変数を一覧します。両ページと簡体字中国語・日本語のミラーは同じ変更で
  更新されています。

## 検証

- バックエンド `go build ./...`、`go vet ./...`、`go test ./...`：成功。
- フロントエンド ESLint、Vite 本番ビルド、Vitest（17 ファイル、131 テスト）：成功。
- 契約テストはレシピ応答をシリアライズし、既存キーの値が変わらないことと、新しいヒントが
  設定値と一致することを検証します。ハンドラーテストは応答エンベロープを確認します。
- 設定テストは既定値、境界、および `CLIENT_ACTIVE_SESSION_CONCURRENCY` と
  `V2_MAX_ACTIVE_SESSIONS_PER_USER` の関係をカバーします。
- Python requirements lock 検証と GitBook ドキュメント検証：成功。

## インストール

開発イメージは明示的にプルする必要があります：

```bash
docker pull jaykserks/summerain:dev-v2.0.9
```

同等の正確な開発タグ：

```text
jaykserks/summerain:dev-2.0.9
```

移動する `dev` タグも最新の成功した開発ビルドを指します。`latest`、`main`、および
安定したセマンティックバージョンエイリアスはこのリリースによって変更されません。

v2.0.8 からのアップグレードにデータベース移行や API 移行は不要です。

## 既知の制限

- ヒントは助言値です。このリリースではフロントエンドを変更しておらず、後続のクライアント
  設定フェーズで読み取りを開始します。
- `V2_MAX_ACTIVE_SESSIONS_PER_USER` を設定済みの
  `CLIENT_ACTIVE_SESSION_CONCURRENCY` より小さくすると、不一致を黙って無視せず起動が
  失敗するようになりました。
- アニメーション画像のサポートは今後のリリースで計画されています。
