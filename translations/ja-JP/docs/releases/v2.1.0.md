# v2.1.0 - V2 シリーズ初の正式リリース

> 正式リリースです。`main` から公開され、安定版エイリアス（`latest`、`main`、`2.1`、`2`
> と正確なタグ）および Docker Hub の説明を更新します。V2 は引き続きアーリー段階の
> メジャーラインです。

## 概要

v2.1.0 は v2.0.0 以来の初の正式リリースです。開発シリーズ v2.0.1〜v2.0.15 のすべてを
1 つのサポート対象リリースに統合します。リソースを考慮したアップロードパイプライン、
サーバー側の画像レシピ、ローカライズ済みの Web アプリケーション、文書化された Docker
デプロイを含みます。開発専用の挙動は含まれず、すべての変更は事前に `dev` チャンネルで
公開・検証済みです。

## ハイライト

### アップロードパイプラインと画像ポリシー

- ブラウザー処理のプリフライトと中断可能なアップロード復旧（再開可能セッションと
  クライアントのポーリング期限を含む）。
- 固定画像ポリシー（バリアント、ピクセル/バイト上限、受け付けるソース形式）は
  サーバー側レシピファイルにあり、本番プロビジョニング用のスキーマ SQL スナップショットを
  提供します。
- レシピエンドポイントはクライアントヒントを返し、フロントエンドは上限付き
  フォールバックを伴ってサーバーのアップロードポリシーに従います。
- 残る V1 互換上限は設定可能で、起動パフォーマンス設定はすべて上限付きです。

### Web アプリケーション

- 上限付きのクライアントクラッシュ報告エンドポイントが、レンダリングクラッシュ、
  未捕捉エラー、未処理の Promise 拒否をデータベース状態なしでサーバーログに記録します。
- サーバーのエラーメッセージは英語で、フロントエンドがエラーコードを 3 言語の UI テキストへ
  対応付けます。

### ドキュメントとローカライズ

- 英語優先の 3 言語ドキュメント、強化された GitBook 検証ツール、サードパーティ帰属と
  公開サードパーティソフトウェアページ。
- 監査フォローアップ：ロールバック統合テストを CI で実行、開発用 imgproxy がホスト所有
  データを読み取り可能、V1 動的変換の有界拒否を文書化。

### デプロイと運用

- フェイルファストなデータベースブートストラップ（advisory lock と不変チェックサム
  マイグレーション）、監督付きワーカー停止、明示的な設定境界。
- 本番デプロイは小さなディレクトリ構成（Compose ファイル、`.env`、
  `config/image-recipe.json`）を使用し、レシピはイメージに焼き込まれたレシピを
  読み取り専用で上書きします。

## 検証

リリース時点：バックエンド標準スイートとスコープ付き MySQL 統合テストが成功。フロント
エンドは lint、build、22 テストファイル 164 テストが成功。requirements lock 検証が成功し、
GitBook ドキュメント検証は各言語 39 ページで成功。ローカル負荷検証では、文書化された
同時実行境界下での安定動作と、動的変換飽和時の有界拒否を確認しています。

## インストール

安定版イメージは正確なバージョンで取得します。

```bash
docker pull jaykserks/summerain:2.1.0
```

同等の正確なタグ：

```text
jaykserks/summerain:v2.1.0
```

安定版エイリアス（`latest`、`main`、`2.1`、`2`）、コミットタグ、OCI マルチプラットフォーム
インデックスも利用できます。本番では正確なタグまたは OCI インデックスダイジェストを
固定してください。

## アップグレードノート

- v2.0.0（前回の正式リリース）からのアップグレード：起動時に増分マイグレーションが
  自動適用されます。先に MySQL と画像ボリュームをバックアップしてください。
- `.env` を `backend/.env.example` と比較してください。開発シリーズで設定変数とレシピ
  ファイルが追加されています。
- デプロイ用 Compose は `config/image-recipe.json` を読み取り専用でマウントし、ファイルが
  ない場合は起動を拒否します。Compose ファイルの隣に作成してください。
- 開発チャンネルは引き続き `dev` です。正式リリースは `main` からのみ公開されます。

## 既知の制限

- V2 は引き続きアーリー段階のメジャーラインであり、今後のマイナーで挙動が変わる可能性が
  あります。
- アニメーション画像と GIF には対応していません。V2 は固定バリアントのみを永続化します。
- 既存の V1 画像は自動変換されず、過去の R2 移行は別ツールに委任されます。
- CI はスコープ付き MySQL 統合サブセットのみを実行します。全量統合スイートには
  ドキュメント記載の DSN 変数が必要です。
