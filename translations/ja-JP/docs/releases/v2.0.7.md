# v2.0.7 - V1 残りの制限の設定化

> 開発プレリリース版。このリリースは `dev` から公開され、迅速なフォローアップ変更を受ける可能性があり、デフォルトの `latest` イメージでは選択されません。

## 概要

v2.0.7 は V1 互換パスの残りのハードコードされた制限をデプロイメント環境変数に移動します。レスポンスサイズ制限、タイムアウト値、マルチパートメモリバッファは起動時に一度読み取られ、明示的な範囲チェックとタイムアウト関係ルールで検証され、変更には再起動が必要です。

起動検証は `IMGPROXY_REQUEST_TIMEOUT` が `V1_GENERATION_TIMEOUT` より厳密に小さいことを保証し、すべての動的変換が失敗する設定エラーを防ぎます。

このリリースはデータベーススキーマバージョンを追加せず、HTTP またはアップロード API を変更せず、画像処理レシピも変更しません。

## 変更内容

### V1 レスポンスとタイムアウト制限

- `V1_DYNAMIC_MAX_RESPONSE_BYTES` は動的変換レスポンスを制限します。デフォルト 100663296（96 MiB）、範囲 1 MiB ～ 512 MiB。
- `V1_BACKGROUND_MAX_RESPONSE_BYTES` はバックグラウンドフォーマット変換レスポンスを制限します。デフォルト 33554432（32 MiB）、範囲 1 MiB ～ 256 MiB。
- `V1_GENERATION_TIMEOUT` は imgproxy 操作の総生成タイムアウトを設定します。デフォルト 35s、範囲 5s ～ 5m。
- `IMGPROXY_REQUEST_TIMEOUT` は imgproxy リクエストの HTTP クライアントタイムアウトを設定します。デフォルト 30s、範囲 5s ～ 5m、かつ `V1_GENERATION_TIMEOUT` より**小さくなければなりません**。
- `V1_MULTIPART_MEMORY_BYTES` は Gin マルチパートフォームメモリバッファを設定します。デフォルト 8388608（8 MiB）、範囲 1 MiB ～ 64 MiB。

### 設定検証

- 5 つの新しい変数すべてに明示的な範囲チェックを含む起動検証を追加しました。
- **重要な検証**：起動検証は `IMGPROXY_REQUEST_TIMEOUT >= V1_GENERATION_TIMEOUT` の設定を拒否し、MySQL または Redis に接続する前に明確なエラーを返します。これにより、すべての動的変換がタイムアウトするサイレント障害を防ぎます。
- タイムアウト関係により、imgproxy は呼び出し元のコンテキスト期限が切れる前に完了してエラーを返す時間を確保します。

### ハードコード定数の削除

- `internal/handler/public_handler.go` から定数 `v1DynamicMaximumResponseBytes`（96 MiB）、`v1BackgroundMaximumResponseBytes`（32 MiB）、`v1GenerationTimeout`（35s）を削除しました。
- `PublicHandler` は完全な `ImageV1Config` を保存し、すべての制限チェックとタイムアウト値に使用します。
- imgproxy HTTP クライアントタイムアウトは、ハードコードされた 30s ではなく `v1Limits.ImgproxyRequestTimeout` から設定されます。
- Gin ルーターの `MaxMultipartMemory` は `cmd/server/main.go` の `cfg.ImageV1.MultipartMemoryBytes` から設定されます。

### 可観測性

- 起動サマリーに 5 つの新しい V1 制限を含む追加行を記録するようになりました：`v1_dynamic_max_response_bytes`、`v1_background_max_response_bytes`、`v1_generation_timeout`、`imgproxy_request_timeout`、`v1_multipart_memory_bytes`。

### デプロイメント例

- `backend/.env.example` はすべての新しい変数を文書化し、起動時のみの制限であり、検証され、管理者 API を通じて公開されないことを説明するコメントを含みます。

開発イメージは明示的にプルする必要があります：

```bash
docker pull jaykserks/summerain:dev-v2.0.7
```

移動する `dev` タグも最新の成功した開発ビルドを指します。`latest`、`main`、および安定したセマンティックバージョンエイリアスはこのリリースによって変更されません。
