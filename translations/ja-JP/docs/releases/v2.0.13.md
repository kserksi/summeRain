# v2.0.13 - エラーメッセージの英語化とクライアント側ローカライズ

> 開発プレリリースです。本リリースは `dev` から公開され、急速なフォローアップ変更を受ける
> 可能性があり、既定の `latest` イメージには選択されません。

## 概要

v2.0.13 は、すべてのバックエンドエラーメッセージ、通知、コメントを英語にし、ユーザーに
表示されるエラー文言をフロントエンドの `code` からロケールへの対応表へ移します。コードに
ローカライズされた文言がない場合にのみ、フロントエンドはサーバーメッセージへフォール
バックします。英語および日本語のインターフェースに中国語の文言は表示されなくなります。

本リリースによる API 契約やデータベーススキーマの変更はありません。

## 変更

### バックエンド

- すべての `errcode` メッセージ、インラインのエラー文言、通知のタイトルと本文、および
  ソースコメントを英語に翻訳しました。エラーコードと HTTP ステータスは変更していません。
- 値を持つ通知は、クライアントが補間してローカライズできるよう、構造化メタデータ
  （クォータ警告の `percent`、クォータ変更の `quota`）に値を保存するようになりました。

### フロントエンド

- `apiErrorMessage` を追加しました。`ApiError` のコードを `errors.<code>` のロケール項目で
  解決し、未対応のコードではサーバーメッセージへフォールバックします。
- パスワード変更、画像削除、アップロード失敗の各画面にこのヘルパーを適用しました。通知は
  `type` ベースのロケールテンプレートとメタデータの補間で描画され、管理画面の言語
  セレクターはロケールラベルを使用します。
- 3 つのロケールすべてに 23 個のエラーコード項目、6 個の通知テンプレート、4 個の
  アップロード復旧フォールバック、言語名ラベルを追加しました。
- 残っていた中国語のソースコメントを翻訳しました。

### ドキュメント

- API リファレンスが英語 `message` のフォールバックとクライアント側の `code` 対応を
  説明するようになり、3 言語すべてを更新しました。

## インストール

開発イメージは明示的に取得する必要があります。

```bash
docker pull jaykserks/summerain:dev-v2.0.13
```

同等の正確な開発タグ：

```text
jaykserks/summerain:dev-2.0.13
```

移動タグ `dev` は最新の成功した開発ビルドも指します。本リリースは `latest`、`main`、安定版
セマンティックバージョンのエイリアスを変更しません。

v2.0.12 からのアップグレードにデータベースマイグレーションや API マイグレーションは
不要です。

## 既知の制限

- `type` が未知の通知は保存されたテキストへフォールバックし、それは以前のリリースの
  ものである可能性があります。
- アップロード復旧のフォールバック文言は失敗の記録時にローカライズされます。後から
  インターフェース言語を変更しても、永続化済みの失敗は再翻訳されません。
- ロケール項目がないエラーコードは英語のサーバーメッセージへフォールバックします。
