# v2.0.5 - 設定境界

> 開発プレリリースです。本リリースは `dev` から公開され、短期間で変更が
> 加えられる可能性があります。また、既定の `latest` イメージでは選択されません。

## 概要

v2.0.5 では、設定ソース間の責務境界を明確にします。デプロイ設定は環境変数に残し、
固定の画像レシピはサーバー側で管理し、管理者が管理する業務設定だけを既存の設定 API から
書き込み可能にします。

管理者向け設定 API は、データベーストランザクションを開始する前に明示的な許可リストを
検証します。未知のキーやデプロイ・プロトコル用のキーは `system_configs` に保存されず、
拒否されます。

本リリースでは、データベーススキーマバージョン、HTTP またはアップロード API、
画像処理レシピを変更しません。

## 変更点

### 管理者設定の許可リスト

- 管理者が書き込み可能なシステム設定の許可リストを 1 か所に追加しました。
  `site_language`、`captcha_provider`、`captcha_site_key`、`captcha_secret`、
  `private_token_ttl_default_ms`、`watermark_*`、`r2_*` です。
- データベーストランザクションを開始する前に未知のキーを拒否します。
- `DB_*`、`REDIS_*`、`V1_*`、`V2_*`、`IMGPROXY_*`、`MAX_JSON_BODY_BYTES` などの
  デプロイ・プロトコル用キーと画像レシピのキーを拒否します。
- 空の設定キーはパラメーターエラーとして拒否します。
- 既存の CAPTCHA、R2、ウォーターマークの検証ルールは維持します。

### テスト

- 許可された業務設定、拒否されるデプロイ・プロトコルキー、空キーの拒否を検証します。

## インストール

開発イメージは明示的に pull する必要があります。

```bash
docker pull jaykserks/summerain:dev-v2.0.5
```

同等の正確な開発タグ:

```text
jaykserks/summerain:dev-2.0.5
```

移動可能な `dev` タグも最新の成功した開発ビルドを指します。本リリースでは
`latest`、`main`、安定版セマンティックバージョンのエイリアスは変更されません。

v2.0.4 からのアップグレードにデータベースまたは API の移行は不要です。

## 既知の制限

- この許可リストが制限するのは管理者設定 API だけです。起動レベルの環境変数は
  プロセス起動時に一度だけ読み込まれます。
- 完全な固定画像レシピは引き続きサーバー側の責務であり、今後のリリースで提供します。
- アニメーション画像への対応は今後のリリースで予定されています。
