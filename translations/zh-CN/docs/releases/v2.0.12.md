# v2.0.12 - 文档合规与第三方署名

> 开发预发布版本。本版本从 `dev` 发布，可能快速跟进变更，不会被默认 `latest` 镜像选中。

## 概述

v2.0.12 将英文文档确立为唯一且整合的权威来源，修复其合规缺口，并依据定稿英文重新同步两种译文。本版本还新增了许可政策要求的第三方署名页面，并加固 GitBook 校验器，使其能够拦截表情符号、结构漂移与过期版本串。

本版本不改变任何服务端行为或 API 契约。

## 变更

### 文档整合

- README：删除重复的请求链路图与重复的阈值/连接池数字；能力表述改为与版本无关；发布说明链接指向 GitHub Releases 页面；标注已归档设计记录；技术栈表链接到署名页面。
- USAGE：统一 Go 版本表述（1.24+，CI 使用 1.26.5）；本地快速开始指向 README；配置参考已与代码和 `.env.example` 逐项核对（包括 `GOMEMLIMIT` 由 Compose 注入）；Worker 名称与管理器一致；限制表不再保留维护者来源列；nginx 请求体上限由 20m 修正为 64m。
- API：删除已失效的 mock 字段映射章节；错误码表按数字排序；删除校对基线说明与文末生成脚注。
- CONTRIBUTING：明确以 Google Go Style Guide 为权威基线；补充前端检查与文档维护规则。
- SECURITY：统一仓库 URL；补充开发构建的支持版本说明。
- `backend/.env.example`：镜像示例保留精确稳定标签，并附带生产固定指引。

### 第三方署名

- 新增 `docs/THIRD-PARTY.md`：以作者、许可证和链接列出所采用的库、服务与工具链；同步扩充 `NOTICE`。
- `libvips`（LGPL-2.1-or-later）与 Redis 8（RSALv2/SSPLv1/AGPLv3）均按未修改、独立部署的组件记录。

### 译文同步

- 简体中文与日文页面依据定稿英文重新同步；清除中文 API 页残留的表情符号与编辑性标题；统一术语；翻译新的署名页面；刷新三份导航与翻译源哈希。

### 校验器加固

- `scripts/verify-gitbook-docs.sh` 现在会拒绝现行页面中的表情符号与过期 `v2.0.0` 引用，并要求译文与英文在标题、表格和代码块结构上保持一致。归档设计记录与按日期归档的发布说明作为历史记录豁免。

## 验证

- 后端 `go build ./...`、`go vet ./...`、`go test ./...`：通过。
- 前端 `npm run lint`、`tsc -b` 与 Vite 生产构建：通过。
- 前端 Vitest：21 个测试文件、161 项测试通过。

## 安装

开发镜像需显式拉取：

```bash
docker pull jaykserks/summerain:dev-v2.0.12
```

等效的精确开发标签：

```text
jaykserks/summerain:dev-2.0.12
```

移动标签 `dev` 也指向最新的成功开发构建。本版本不会更新 `latest`、`main` 或稳定版语义化别名。

从 v2.0.11 升级无需数据库迁移或 API 迁移。

## 已知限制

- 文档描述最近一次稳定发布；未发布改动在发布前可能仅存在于 `dev`。
- README 的发布链接指向 GitHub Releases 页面，因此不固定单个版本。
- 动图支持仍列入后续发布计划。
