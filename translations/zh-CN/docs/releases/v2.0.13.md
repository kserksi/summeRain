# v2.0.13 - 错误消息英文化与前端本地化

> 开发预发布版本。本版本从 `dev` 发布，可能快速跟进变更，不会被默认 `latest` 镜像选中。

## 概述

v2.0.13 将全部后端错误消息、通知与注释改为英文，并把用户可见的错误文案交给前端的 `code` 本地化映射；仅当错误码没有对应译文时，前端才回落到服务器消息。英文与日文界面中不再出现中文文案。

本版本不改变 API 契约或数据库结构。

## 变更

### 后端

- 将全部 `errcode` 消息、内联错误文案、通知标题与正文，以及源码注释翻译为英文；错误码与 HTTP 状态保持不变。
- 带数值的通知改为在结构化 metadata 中保存数值（配额预警的 `percent`、配额调整的 `quota`），以便客户端插值本地化。

### 前端

- 新增 `apiErrorMessage`：按 `errors.<code>` 解析 `ApiError` 错误码，未映射时回落到服务器消息。
- 将该助手应用于修改密码、删除图片与上传失败等界面；通知改为按 `type` 的本地化模板渲染并插值 metadata；后台语言选择器使用本地化标签。
- 三份 locale 新增 23 个错误码条目、6 个通知模板、4 条上传恢复兜底文案与语言名称标签。
- 翻译剩余的中文源码注释。

### 文档

- API 参考现在说明英文 `message` 兜底语义与前端 `code` 映射，三语同步更新。

## 安装

开发镜像需显式拉取：

```bash
docker pull jaykserks/summerain:dev-v2.0.13
```

等效的精确开发标签：

```text
jaykserks/summerain:dev-2.0.13
```

移动标签 `dev` 也指向最新的成功开发构建。本版本不会更新 `latest`、`main` 或稳定版语义化别名。

从 v2.0.12 升级无需数据库迁移或 API 迁移。

## 已知限制

- `type` 未知的通知会回落到其存储文本，可能来自更早版本。
- 上传恢复兜底文案在记录失败时本地化；之后切换界面语言不会重译已持久化的失败记录。
- 没有本地化条目的错误码会回落到英文服务器消息。

## 相关工作

本版本完成 v2 路线图的错误消息本地化阶段。后端现已仅使用英文，用户可见错误文案由前端负责。
